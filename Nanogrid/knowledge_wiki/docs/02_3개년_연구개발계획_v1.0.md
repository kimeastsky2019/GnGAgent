# 자율 에너지 AI — 3개년 연구개발계획 v1.0

> 3개년 연구개발계획 · v1.0 · 2026-09-08 · GnG International · NanoGrid AI System · 기획 v0.2 통합 개정

**최종 목표** — 연구 종료 시점(3차년도 말)에, 에너지 도메인에서 스스로 연구·개발·검증하는
**자율 연구 에이전트**와 Claude 수준 답변을 내는 **사내 sLM(CES ≥ 0.90)** 을 완성하고,
이를 탑재한 **설명가능 EMS 플랫폼**을 다중 사이트에서 상용 실증한다.
사람은 승인과 감사만 수행한다.

## 1. 연구 배경과 필요성

AI 최전선 기업들의 시간표는 향후 5년에 집중된다 — AI의 직원화(에이전트), AI 연구의 자동화,
최고 수준 지능의 대량 복제, 조직 결정권의 이동, 피지컬 AI. 이 전개에서 명시적으로 남는
**물리적 병목이 전력**이다. 에너지 기업인 우리에게 이 미래는 두 개의 기회다.

- **시장** — AI 데이터센터·로봇 공장·EV 플릿은 모두 대형 전력 수요처다. 이들의 전력을
  예측·최적화·자원화하는 지능형 EMS 수요는 시나리오가 진행될수록 커진다.
- **신뢰** — 같은 시나리오의 경고(인간이 이해 못 하는 AI, 형식화된 승인, 끌 수 없는 의존)는
  본 연구의 기반 플랫폼이 이미 설계로 해결한 문제다(사실은 SQL이·서술은 LLM이,
  L0~L3 승인 등급, CES). 이 신뢰 구조 자체가 제품이 된다.

### 연구 3원칙 — 전 연차 공통 설계 제약

1. **끌 수 있는 AI** — 모든 자동화에 수동 운전 모드와 원클릭 롤백을 유지한다.
   가역성이 없는 기능은 연구 산출물로 인정하지 않는다.
2. **이해 가능한 AI** — 모든 판단은 근거 사슬(답변→인사이트→SQL→소스)로 역추적된다.
   설명 못 하는 자동화는 L1 등급을 넘지 못한다.
3. **소유하는 AI** — 판단권을 외부 API에 영구 위임하지 않는다. 사내 sLM이 목적지이고,
   외부 모델은 교사(증류)와 심판(CES)으로만 쓴다.

## 2. 연구 구조 — 플라이휠 위의 두 트랙

연구는 기반 플랫폼(4탭 플라이휠: ①소스 코드 → ②데이터 구축 → ③지식 데이터베이스
→ ④LLM 학습, ④의 산출이 ①②③에 재투입) 위에서 두 트랙으로 진행한다.
**트랙 A(자율화 연구)** 는 사내 AI가 개발·검증·배포를 스스로 수행하는 수준을 연차마다
끌어올리고, **트랙 B(제품화 연구)** 는 그 결과를 에너지 시장의 제품으로 변환한다.
A가 만든 능력이 B의 기능이 되고, B의 현장 데이터가 A의 학습 재료가 된다.

연차 이행 조건은 달력이 아니라 **앞 연차 정량 지표 충족** (§4 감시 지표가 가·감속기).

## 3. 연차별 연구 계획

### 1차년도 「기반·증거」 — "AI 직원" 체제의 완성과 계측

에이전트가 문서·예측·분석 업무를 수행하고 사람이 승인하는 체제를 운영 실적
(자동화율·개입 건수)으로 계측 가능하게 만들고, 학습 데이터와 평가 체계를 본궤도에 올린다.
후반기에 에이전트의 코드 개발(L2)을 파일럿한다.

**A · 자율화 연구**
- 공식 CES 정례화 (주 1회, Claude 심판·버전 고정) + judge–인간 불일치율 감사
- 골든셋 100 → 500문항 (챗 문답 승격 경로 활용)
- `training_pairs` 승인 페어 1만 축적 (전 탭 로깅 후킹)
- 자동화율 계기판 — 자동 처리/인간 개입을 지식 DB 화면에 상설
- 에이전트 PR 파일럿(예측 모델 교체) → 승인율 검증 후 L2 상시화
- sLM SFT 1차(LoRA) — 승인 페어 + 교사 증류 데이터

**B · 제품화 연구**
- EMS 지식위키 상용 v1 — TNO 실증 완료 보고 (주간 리포트 = 성능 증거물)
- SP-G 실계측 전환 (시뮬레이터 병행 운전) — **크리티컬 패스**
- 설명가능 EMS: 모든 제어 제안에 근거 사슬 UI 첨부
- AI-DC 전력 수요 1페이저 · 파일럿 영업 개시
- 백업·DR 체계(일일 덤프·오프사이트·복구 리허설) 완성

**1차년도 정량 지표**: CES ≥ 0.70 · 골든셋 500 · 승인 페어 1만 · 자동화율 55% ·
MAPE ≤ 10% · 결측률 ≤ 2% · 에이전트 PR 승인율 ≥ 60%

### 2차년도 「자율 연구」 — 에이전트가 연구를 완주한다

에이전트가 연구 주제 선정→실험 설계→실행→분석→개선안 보고까지 스스로 완주하는
**자율 연구 에이전트 1호**를 에너지 예측·운영 최적화 도메인에서 가동한다.
사내 sLM이 도메인 모델 후보 수준(CES ≥ 0.80)에 도달하고, 제품은 다중 사이트로 확장된다.

**A · 자율화 연구**
- 자율 연구 에이전트 1호 — `forecast_experiments` + 인사이트 파이프라인을 결합해
  주간 단위 연구 사이클 자동화, 인간은 주간 리뷰
- 승인 페어 10만 (멀티사이트 실계측 포함), SFT 2차 → 도메인 sLM 후보
- sLM 재투입 실험 — 인사이트 서술·명세서 작성·예측 해설을 사내 모델이 수행,
  플라이휠 되먹임의 효과를 CES로 계측
- 에이전트 조직 설계 — 사이트당 에이전트 셋(수집·분석·보고) 복제 배포 구조

**B · 제품화 연구**
- 멀티사이트 관제 (N ≥ 3) — 사이트 간 지식 공유 위키
- 맞춤 운영 전략 서비스 — 자율 연구 에이전트 산출의 고객별 상품화
- AI-DC 전력 관리 파일럿 1건 계약 (예측 + 수요반응)
- VPP(가상발전소) 어그리게이션 연구 착수
- 규제 대응: AI-Gov 법률 파이프라인에 전력·AI 신규 법안 상시 투입

**2차년도 정량 지표**: CES ≥ 0.80 · 승인 페어 10만 · 자동화율 70% · 인간 개입 ≤ 20건/주 ·
MAPE ≤ 8% · 자율 연구 사이클 ≥ 12회 완주 · 상용 사이트 ≥ 3

### 3차년도 「위임·스케일」 — 결정권 이동에 앞서 안전 구조를 검증한다

도메인 sLM을 완성(CES ≥ 0.90)하고, 시나리오의 "결정권 이동·피지컬 AI" 단계에 앞서
**제한 위임의 안전 구조**를 실증한다 — 저위험 설비 제어를 한도 내에서 자동화하되,
승인 버튼이 형식화되지 않았음을 계측으로 증명한다. 이 신뢰 구조를 제품·증적으로
시장에 내놓는다.

**A · 자율화 연구**
- 도메인 sLM 완성 — CES ≥ 0.90, 온프렘 서빙 (판단권의 사내화)
- L3 부분 위임 실험 — 배터리 디스패치 등 저위험 제어를 한도 내 자동화
- **거부 가능성 계측** — 대안 제시 의무, 인간 거부율·번복률, judge–인간 불일치율을
  상설 지표로 (승인이 형식이 아님의 증명)
- 실제어 안전 규칙 엔진 — 물리 한계(계약전력·SoC 하한)는 AI 밖에 하드코딩,
  제안-승인-실행-감사 4단 분리

**B · 제품화 연구**
- V2G·EV 충전 실제어 실증 (OCPP) — 피지컬 단계의 전력 파트너 포지션
- 로봇 공장·AI-DC 마이크로그리드 EMS 레퍼런스 1건
- AI-Gov 준수 증적 자동화의 제품화 — 규제 시장 진입 장벽 구축
- VPP 상용 전환 검토 (참여 용량·정산 구조)

**3차년도 정량 지표 (최종)**: CES ≥ 0.90 · 자동화율 90% · 인간 개입 ≤ 5건/주 ·
L3 안전사고 0 · MAPE ≤ 7% · 실제어 실증 사이트 ≥ 1 · 상용 사이트 확대

## 4. 추진 체계와 속도 조절

### 역할 — 에이전트가 수행하고 사람이 승인한다

| 등급 | 행위 | 통제 |
|---|---|---|
| L0/L1 | 분석·문서·예측 생성 | 자동 + 사후 샘플링 감사 (승인 큐) |
| L2 | 코드 변경·모델 교체 | 에이전트 생성 → 인간 승인 후 반영 |
| L3 | 설비 제어·프로덕션 배포·규제 판정 확정 | 인간 승인 필수 · 감사 로그 · 롤백 SLA (3차년도에 한도 내 부분 위임 실험) |

### 속도 조절 — 분기 점검 감시 지표

연차 이행은 달력이 아니라 지표 충족으로 판정하고, 아래 외부 신호로 가·감속한다.
신호는 지식위키의 시그널 문서로 축적해 분기 브리프를 자동 발행한다.

- 에이전트 코딩 실용화 — 자체 L2 실험의 PR 승인율·수정률
- sLM 품질 상승 속도 — 공식 CES 분기 추이 (+0.05 미만이면 RAG 고도화 유지)
- 국내 AI-DC·로봇 공장 투자 발표 — B 트랙 영업 개시 신호
- 전력·AI 규제 동향 — AI-Gov 파이프라인 상시 투입
- V2G·양방향 충전 표준화(OCPP/ISO 15118) — 실제어 연구 가속 신호

## 5. 리스크와 대응

| 리스크 | 영향 | 대응 |
|---|---|---|
| SP-G 실계측 전환 지연 | 학습 데이터·실증 증거 부족 (크리티컬 패스) | 시뮬레이터 병행 운전 유지, 1차년도 상반기 최우선 배정 |
| sLM 품질 정체 (CES 미달) | 연차 이행 지연 | 연차 이행을 지표에 걸어 자동 지연 — RAG 고도화로 제품 가치는 유지 |
| GPU·학습 비용 | SFT 일정 압박 | 학습은 클라우드 버스트, 서빙은 온프렘 분리. 심판(CES)은 저비용 채점 호출 |
| 단일 서버·데이터 유실 | 연구 연속성 | 일일 백업 가동 중 → 오프사이트·복구 리허설로 확장 (1차년도) |
| 시나리오 가속 (경쟁 조기 진입) | 시장 선점 실기 | 감시 지표 분기 점검으로 B 트랙 항목을 앞당길 수 있는 모듈형 계획 |
| 과잉 위임 (승인 형식화) | 신뢰·안전 사고 | 거부 가능성 계측을 3차년도 정식 연구 항목으로 — 원칙 ①②가 게이트 |

## 6. 기대 성과와 활용

- **기술 성과** — 에너지 도메인 sLM(CES ≥ 0.90), 자율 연구 에이전트, 제한 위임 안전 구조
  (거부 가능성 계측 방법론) — 각각 논문·특허·표준 제안 후보
- **제품 성과** — 설명가능 EMS 플랫폼(멀티사이트), AI-DC 전력 관리, V2G 실제어,
  AI-Gov 준수 증적 자동화
- **증거 성과** — 전 기간의 주간 성능 리포트·승인 큐·감사 로그가 그대로 실증 증거물이자
  후속 과제의 데이터가 된다 (사실은 SQL이, 서술은 LLM이)
